# EDMdev — 夢想智賦商業開發 EDM

商業開發（陌生開發）用的 EDM HTML 模板。所有版型都是 email-safe：
table 排版、樣式 inline、僅用 `@media max-width:480px` 做手機微調，可直接複製貼進發信平台。

## 資料夾結構

```
templates/
  <發送日 YYYYMMDD>/
    夢想智賦_EDM_<地區>_<日期>.html
```

## 換地區版本要改的地方

- `<title>` 與 header 主標中的地區名
- preheader（隱藏摘要文字）
- `03` 區塊：換成該縣市的地方補助方案與 `dreamrich.com.tw/subsidy/<id>` 連結
- 其餘中央級補助（01、02、04、05）通常可沿用
